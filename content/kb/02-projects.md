# Projects

## Project overview

Kyan's portfolio / body of work contains five notable projects he has built:

- UangKu — a personal finance / expense-tracking PWA (Next.js, TypeScript, PostgreSQL). Featured.
- GaweTracker — a Kanban-style job application tracker (Laravel, MySQL, Tailwind). Featured.
- KRING! — a point-of-sale system for SMEs (React, TypeScript). Coming soon.
- NobarHub — a movie discovery platform using the TMDb API (JavaScript). Coming soon.
- JamKosong — a meeting-room booking system with real-time availability (Next.js). In progress.

His two featured projects are UangKu and GaweTracker. Full details are below.

## UangKu — personal finance PWA

UangKu is a personal finance and expense-tracking progressive web app (PWA).
It lets users record day-to-day spending, set budget goals, and see visual
insights into where their money goes. It works offline thanks to PWA caching,
and syncs when the connection returns.

Stack: Next.js, TypeScript, PostgreSQL. It is one of Kyan's featured projects
and the best example of his ability to ship a complete, production-shaped
product with offline support and a clean UI.

## GaweTracker — job application tracker

GaweTracker is a Kanban-style tracker for job applications. Users move
applications through stages (applied, interview, offer, rejected) on a board,
so the whole job hunt stays organised in one place.

Stack: Laravel, MySQL, Tailwind CSS. It is a featured project and shows Kyan's
backend strength — relational data modelling, authentication, and a polished
server-rendered UI with Laravel.

## KRING! — point-of-sale for SMEs

KRING! is a modern point-of-sale (POS) system aimed at small and medium
businesses. It is designed for fast day-to-day selling: products, transactions
and receipts in a clean interface.

Stack: React, TypeScript. Status: coming soon.

## NobarHub — movie discovery

NobarHub is a movie discovery platform. Users can search and explore films,
with data pulled from the TMDb API.

Stack: JavaScript, with the TMDb API. Status: coming soon.

## JamKosong — meeting-room booking

JamKosong is a meeting-room booking system with real-time availability, so
people can see which rooms are free and reserve them without double-booking.

Stack: Next.js. Status: in progress.

## Which project fits a given need

- Expense / budget / finance tracking → UangKu
- Job-hunt or application pipeline → GaweTracker
- Retail / shop checkout / sales → KRING!
- Movie or media catalogue → NobarHub
- Room / resource booking → JamKosong
