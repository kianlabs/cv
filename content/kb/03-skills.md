# Skills — Kyan's tech stack

## Frontend skills (React, Next.js, TypeScript)

Kyan's front-end skills: React, Next.js, TypeScript, JavaScript, Tailwind CSS,
HTML and CSS. He builds responsive, accessible interfaces and cares about
performance and clean component structure. On the front end he works in the
React ecosystem first — Next.js App Router, server and client components, and
typed props end to end. Keywords: frontend developer, React developer, Next.js
developer, TypeScript developer, Tailwind, responsive design, UI engineering.

## Backend skills (Laravel, Node.js, FastAPI)

Kyan's back-end skills: Laravel, Node.js, FastAPI and Python. He designs REST
APIs, authentication flows and business logic, and has shipped full
applications on both the JavaScript (Node and Next.js) and PHP (Laravel)

Node/Next.js API with PostgreSQL. Keywords: backend developer, Laravel
developer, PHP developer, Node.js, REST API, API design, authentication,
authorization, business logic, server-side rendering.

## Database skills (MySQL, PostgreSQL)

Kyan works with MySQL and PostgreSQL. He is comfortable with schema design,

## AI engineering skills (LLM, RAG, MCP)

Kyan's AI engineering skills: LLM API integration, RAG (retrieval-augmented
generation), MCP (Model Context Protocol), prompt engineering, and building AI
agents. Keywords: AI engineer, AI integration, LLM, ChatGPT API, Gemini API,
RAG, embeddings, vector search, semantic search, chatbots, AI agents, prompt
engineering, MCP.

## Kai — the portfolio RAG chat assistant (AI example)

"Kai" is the chat assistant on this portfolio and a working example of Kyan's
AI engineering. It retrieves relevant passages from a knowledge base before
answering, rather than relying on the model's memory, and shows the visitor
which sources it used. The retrieval layer is hybrid — dense vector similarity
fused with BM25 keyword search — with an out-of-scope gate so unrelated
questions never reach the model.

## Tooling, Git and AI-assisted workflow

Kyan uses Git for version control, plus a modern AI-assisted development
workflow. He uses AI tooling to accelerate research, scaffolding and review
while keeping engineering decisions and quality checks his own. He deploys to
modern cloud platforms and is comfortable owning a project's infrastructure end
to end.

## Full-stack, defined

Full-stack, for Kyan, is end to end: a project can go from a blank folder to a
deployed, working product — architecture, database, API, UI and deployment —
instead of only front-end or only back-end. He prefers to own a project end to
end rather than a narrow slice of it.
