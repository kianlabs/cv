# Skills

## Frontend

React, Next.js, TypeScript, JavaScript, Tailwind CSS, HTML/CSS. Kyan builds
responsive, accessible interfaces and cares about performance and clean
component structure.

## Backend

Laravel, Node.js, FastAPI, Python. He is comfortable designing REST APIs,
authentication, and business logic, and has built full applications on both
the JavaScript (Node/Next) and PHP (Laravel) ecosystems.

## Databases

MySQL and PostgreSQL. Comfortable with schema design, relations, indexes and
writing efficient queries.

## AI engineering

LLM API integration, RAG (retrieval-augmented generation), MCP (Model Context
Protocol), prompt engineering, and building AI agents. This portfolio's own
chat assistant is an example — it uses retrieval over a small knowledge base
before answering.

## Tooling

Git for version control, and a modern AI-assisted development workflow. Kyan
uses AI tooling to accelerate research, scaffolding and review while keeping
engineering decisions and quality checks his own.

## What "full-stack" means for Kyan

End to end: he can take a project from a blank folder to a deployed, working
product — architecture, database, API, UI, and deployment — rather than only
front-end or only back-end.
